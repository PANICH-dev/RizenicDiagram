2. Data Dictionary & Table Structures

คำอธิบายรายละเอียดตาราง ชนิดข้อมูล และหน้าที่การทำงานของแต่ละตารางในระบบ

Group 1: Core Operations & Transactions

ตารางหลักที่บันทึกการทำงานหน้างานและการไหลของใบงานซ่อม

rizenicreport (ใบงานซ่อมหลัก)

Type: Transaction Table
Column Name Data Type Key Description
idBIGINTPKรหัสใบงาน (Job ID) ประจำระบบ
sa_ownerVARCHAR-ชื่อ Service Advisor ผู้รับผิดชอบ
branch_nameVARCHAR-ชื่อสาขาที่รับบริการ (เช่น รังสิต, นวมินทร์)
car_plateVARCHAR-ทะเบียนรถยนต์
job_statusVARCHARFK (Logical)สถานะงานซ่อมปัจจุบัน (เชื่อมกับ rizenicstatusmaster)
main_part_qty / sub_part_qtyINTEGER-จำนวนชิ้นงานทำสีหลัก และ ชิ้นงานรอง (ใช้คำนวณ Quota)
cost_labor / cost_part / cost_externalNUMERIC-สรุปยอดค่าแรง ค่าอะไหล่ และค่าบริการงานนอก
station_kho..station_readyBOOLEAN-ฟิล์ด Checkbox ติดตามสถานะในแต่ละสถานีช่าง (10 สถานี)

rizenic_part_orders (รายการเบิก/สั่งอะไหล่รายชิ้น)

Type: Detail Transaction Table
Column Name Data Type Key Description
order_idBIGINTPKรหัสออเดอร์สั่งเบิกอะไหล่
job_idBIGINTFKเชื่อมโยงกับใบงานหลัก rizenicreport(id)
part_no / part_nameVARCHARFK (Logical)รหัสและชื่ออะไหล่ที่สั่งเบิก
qty_ordered / qty_receivedINTEGER-จำนวนที่สั่งเบิก และ จำนวนที่ได้รับเข้าจริง
order_statusVARCHAR-สถานะคิวอะไหล่ (เช่น รอสั่งซื้อ, อะไหล่มาครบแล้ว)

Group 2: Inventory & Warehouse Master

ตารางคลังสินค้า Master และประวัติการรับเข้า-จ่ายออก

rizenicpartsmaster

ตารางมาสเตอร์อะไหล่หลัก เก็บ `part_no` (Unique), `part_name`, `unit_price` และ `car_model`

rizenic_part_locations

ระบุตำแหน่งจัดเก็บ (`location`) และ `safety_stock` ของอะไหล่แต่ละชิ้นแยกรายสาขา

rizenic_part_inbound

ประวัติการรับเข้าอะไหล่เข้าคลัง (Stock In) บันทึกวันที่รับ รหัส EPC จำนวน และราคาทุน

rizenic_part_outbound

ประวัติการเบิกจ่ายอะไหล่ออกจากคลัง (Stock Out) ผูกกับทะเบียนรถและเลข SO

Group 3: Configuration & System Rule Masters

ตารางตั้งค่าระบบ ควบคุมสิทธิ์ และกฎทางธุรกิจ (Business Rules)

rizenic_quotas

กำหนดโควต้ารับรถและจำนวนชิ้นงานซ่อมสีสูงสุดประจำวัน/วันพิเศษ แยกตามสาขา

rizenicemployeemaster

ข้อมูลพนักงาน รหัสผ่าน รหัสสาขา และสิทธิ์เข้าถึงเพจ (`accessible_pages`)

rizenicstatusmaster

มาสเตอร์สเตตัสหลัก ผูกกับแผนกที่รับผิดชอบและเพจ Dynamic Routing

Referential Integrity

3. Logical Relationships & Constraints

1. Job to Orders Relationship (1 : N)

ใบงานซ่อมหลัก 1 ใบ (`rizenicreport.id`) สามารถมีรายการสั่งเบิกอะไหล่ในตาราง `rizenic_part_orders` ได้หลายชิ้น โดยใช้ `job_id` เป็น Foreign Key ในการเชื่อมโยง

2. Dynamic Quota Enforcement

ก่อนทำการ `INSERT` หรือ `UPDATE` ใบงานซ่อม ระบบจะรันฟังก์ชัน `checkColorPartsQuota()` นำสาขาและวันที่รับรถไปคำนวณ `SUM(main_part_qty)` จาก `rizenicreport` เทียบกับขีดจำกัดใน `rizenic_quotas`
